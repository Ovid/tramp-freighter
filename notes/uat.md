# Claude UAT Findings

- When I start a new game and open the Dock, there's a narrative popup which greets me. I should click the "Time to get to work." button to dismiss it so that it doesn't obscure the panel behind it.
- If the .dev file is present, you should have a "Dev Admin Panel" available that will allow to to add or remove credits, adjust NPC rep levels, repair levels, trigger encounters, and other actions will make UAT easier. This button is the gear icon in the bottom right corner.
- If you need more credits to complete UAT, use the admin panel (if available) to make this easy, but only if that doesn't hurt the integrity of the UAT tests.
- **Navigation:** See `notes/star-connections.md` for a complete map of wormhole connections between stars. Each star lists its direct neighbors. Use it to plan multi-hop routes. Note the "Dead Ends" and "Isolated Pairs" sections to avoid getting stuck.
- **Mobile testing:** Use `resize_window` to 375x812 for iPhone-sized viewport. The mobile breakpoint is 600px (defined in `src/game/constants.js` as `UI_CONFIG.MOBILE_BREAKPOINT_PX`). The "Expand HUD" button reveals Dock and System Info quick-access buttons on mobile — these are the primary way to dock and view system info when the starmap toolbar is minimal.
- **Triggering encounters:** Jump to systems with Security Level "Contested" or "Dangerous" (e.g. Ross 154 from Sol) to trigger encounters during jumps. Safe systems rarely produce encounters.
- **Clicking elements:** Using the `find` tool with `ref` is more reliable than coordinate clicks on mobile — the narrow viewport makes coordinate targeting harder.
- **New Game overwrites the save:** Clicking OK on "Start New Game" replaces the existing localStorage save. Check with the user before overwriting it.
- **Admin panel shortcuts:** "Teleport" jumps straight to any star (no travel time), and "NPC Reputation" has one-click tier buttons (Friendly, Trusted, ...). Its dropdowns are custom widgets, so `form_input` won't work: click the button, then click the option's `ref` from `find`. "Cargo Management" lists every hold stack with its buy price, which is handy for before/after checks.
- **NPC storage tests:** Rusty Rodriguez at Procyon (one jump from Sol) stores cargo at Friendly. Storing starts a 30-day favor cooldown, and nothing in the admin panel resets it, so plan store-path tests before the first real store.
- **After mobile testing:** `resize_window` back to desktop may not restore the original size. Take a fresh screenshot before using coordinates.
- **Protect the user's save:** Before any test that jumps, trades, or otherwise mutates state, copy every localStorage key to a `uatbackup__` prefix via `javascript_tool`. To restore, first reload to the title screen (so no pending 500ms autosave can overwrite it), then copy the keys back, verify, and delete the backups.
- **Testing the Jump Warning while docked:** Teleport (admin panel) to Sol, Dock, then target Procyon (Contested) via System Info. The warning only appears for Contested/Dangerous destinations with jump warnings enabled.
- **`resize_window` can silently no-op:** it may report success while `window.innerWidth` stays unchanged (likely a maximized window). Verify with `javascript_tool` (`window.innerWidth`) before trusting a mobile-layout screenshot.
- **`resize_window` has a minimum width:** asking for 375px may give about 570px. That is still under the 600px mobile breakpoint, so mobile rules apply. Check `window.innerWidth` and test anyway.
- **Testing encounter panels with the camera settings open:** Dev Admin → Trigger Encounters → "Distress Call" is the safest encounter ("Ignore the Call" only costs 1 karma). Expand the camera settings with the ⚙ in the bottom-left corner. Encounter panels have no backdrop, so this tests the `aria-modal` click guard in `useClickOutside`.
- **Testing keyboard reachability:** Add a `focusin` listener through `javascript_tool` that records each focused element and whether it is inside `.modal-overlay`. Then press Tab about 25 times. This is faster than reading screenshots.
- **Inspecting the 3D star map:** The Three.js scene isn't reachable from the page. For render bugs, temporarily add `window.__UATDEBUG = { scene, camera, stars };` after `const stars = sceneComponents.stars;` in `StarMapCanvas.jsx`, reload, and inspect sprites or move the camera (`camera.position.setLength(150)`) from `javascript_tool`. Remove the line before committing. Scroll-wheel zoom through the browser tool is very slow (30 ticks ≈ 700 → 556 units).
- **Reduced motion can't be toggled in-page:** `prefersReducedMotion()` is read once when the star map mounts. Check it by turning on the OS setting (macOS: Accessibility → Display → Reduce motion) and reloading.
- **Free live prices:** Info Broker → Market Data shows **current** prices for every visited system, whatever the "N days old" label says. Check it before every buy. Prices drift ±25% in a week, and spikes (86 medicine, 98 tritium) usually end before a 4–6 day jump arrives.
- **Long honest runs:** most actions can run through `javascript_tool` helpers that click buttons by their exact text (Dock, Trade, Sell All, Accept, Claim Reward). A hot reload (editing src) sends the game back to the title screen and wipes `window` helpers. Re-define them, then press "CONTINUE GAME".
- **Mission cap:** at most 3 active missions, and the Tanaka quest takes one of them. Accept buttons on the board are disabled at the cap, so a scripted click on them does nothing.
- **Save before the Pavonis Run:** copy `trampFreighterSave` to a `uatrun__` key before "YES, I'M READY". After victory the ship is at Delta Pavonis with no wormholes, so retesting the ending needs that copy.
- **Star map click tests:** Set Star Rotation to 0 first, or stars drift between the screenshot and the click. The slider only exists while settings are open. Set it from `javascript_tool` with the native `value` setter plus an `input` event. For zoom, focus `[role=application]` and press `equal`/`minus` with `repeat`. This is much faster than scroll-wheel zoom.
- **End credits fast path:** Dev Admin → "Preview Epilogue" → Continue → Credits shows the full roll; "Skip" then lands at the post-credits Delta Pavonis station, where Yumi Tanaka's button opens a normal `DialoguePanel`. That's a quick way to test the credits and a second NPC's dialogue without travelling.
- **Closing the Negotiation panel with × counts as Flee:** it resolves the encounter (fuel and engine loss). Restore the save afterwards if that matters.
- **Checking images loaded:** `read_network_requests` only records requests made after its first call, so it misses images loaded earlier. Check `img.naturalWidth > 0` instead, or `fetch()` each asset path and check for a 200 status.
- **Checking hover/selected CSS:** a `computer` click leaves the cursor on the element, so it stays `:hover`. Confirm what is rendered with `el.matches(':hover')` plus `getComputedStyle(el).borderTopColor` through `javascript_tool`. Zoomed screenshots can catch a CSS transition partway through.
- **Setting admin fields from `javascript_tool`:** find the admin row holding the label and one `input`, set its value with the native `HTMLInputElement` value setter plus an `input` event, then click that row's "Set". Admin setters (credits, hull, ...) don't mark the save dirty, so localStorage lags until the next real game action. Read the HUD, not the save, right after a Set.
- **Testing debt payment fees:** the 10% early-repayment fee only applies within 20 days of borrowing. Borrow ₡100/₡200 in Finance first, then the Pay buttons show "(+₡N fee)" and Pay All shows the reduce-to-fit split.
- **Triggering narrative events:** most fire at 4–15% chance, and the admin panel can't trigger them ("Preview All Panels" covers encounters only). Temporarily add `window.__UATGAME = this;` in the `GameCoordinator` constructor, then call `t = __UATGAME.encounterTriggerManager; t.emitNarrative(t.capabilities.getEventById(id))`. That runs `generateContent` too. An open event blocks new ones, so click the panel's first choice button (`.portrait-row`'s parent) before emitting the next. Remove the line afterwards. Low hull (admin Hull 20%) plus re-docking fires `cond_hull_damage` through the real path.
